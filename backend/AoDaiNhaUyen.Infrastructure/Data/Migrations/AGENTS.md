## For AI Agents
### Working In This Directory
- Do NOT manually edit migration files — use `dotnet ef migrations add <Name>` to generate new ones.
- Run from Infrastructure project directory: `dotnet ef migrations add <Name> --startup-project ../AoDaiNhaUyen.Api`
- Migrations auto-apply on startup when `RunMigrationsAndSeedOnStartup` is true.
- `AppDbContextModelSnapshot.cs` shows current model state — regenerated with each new migration.
- Rollback: `dotnet ef database update <TargetMigration>` or remove last migration with `dotnet ef migrations remove`.
- Connection string resolved by `AppDbContextFactory` from Api project's appsettings or env vars.
- Some migrations (e.g., `20260618090000`, `20260618094000`) lack a `.Designer.cs` — this is expected for manually adjusted migrations.
