# DTOs/Promo

## Purpose
Promo code validation DTOs used during cart/checkout to apply discount codes. Consumed by `IPromoService`.

## Key Files
| File | Description |
|------|-------------|
| `PromoValidationResult.cs` | Validation outcome: `IsValid`, `ErrorCode?`, `ErrorMessage?`, `DiscountAmount`, `FreeShipping`, `DiscountLabel?` |

Note: `PromoValidationResult.cs` also contains `ApplyPromoRequest` (Code, Subtotal).

## For AI Agents

### Working In This Directory
- `DiscountAmount` is the absolute VND value to subtract from the order subtotal (already calculated server-side)
- `FreeShipping` is a boolean flag — when true, shipping fee is waived regardless of `DiscountAmount`
- `DiscountLabel` is a display string for the UI (e.g., `"Giảm 50,000₫"`) — generated by the service
- `ErrorCode` values are checked by the checkout flow to show user-friendly messages

## Dependencies
### Internal
- `IPromoService` — consumes `ApplyPromoRequest`; returns `PromoValidationResult`
- `IAdminPromoService` — admin CRUD for promo codes (uses `DTOs/Admin/AdminPromoDTOs.cs` for its own shapes)
